# Assets Directory

## Files yang Dibutuhkan

Untuk menampilkan gambar Gandrung dan motif batik Banyuwangi di hero section, Anda perlu menambahkan file berikut:

### 1. Gandrung Image
- **Nama file:** `gandrung.png`
- **Ukuran yang disarankan:** 300x400 pixels (portrait)
- **Format:** PNG dengan transparansi
- **Deskripsi:** Gambar penari Gandrung Banyuwangi

### 2. Batik Banyuwangi Image  
- **Nama file:** `batik-banyuwangi.png`
- **Ukuran yang disarankan:** 300x400 pixels (portrait)
- **Format:** PNG dengan transparansi
- **Deskripsi:** Motif batik khas Banyuwangi

## Cara Menambahkan Gambar

1. Siapkan gambar Gandrung dan batik Banyuwangi
2. Rename gambar Gandrung menjadi `gandrung.png`
3. Rename gambar batik menjadi `batik-banyuwangi.png`
4. Copy kedua file ke folder `assets/` ini
5. Refresh halaman website untuk melihat hasil

## Jika Gambar Tidak Tersedia

Website sudah dilengkapi dengan placeholder yang akan otomatis muncul jika gambar tidak ditemukan:
- 💃 Untuk Gandrung
- 🎭 Untuk Batik Banyuwangi

Placeholder ini akan menampilkan icon dan teks yang sesuai sebagai pengganti gambar.
